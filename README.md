# 连点器（Clicker）

Windows 桌面自动化工具，三个功能：**连点**、**录制**、**宏**，另有一个 **选项** 页放
全局快捷键和播放行为设置。

逐页的操作步骤、快捷键写法、数据文件格式和故障排查见 **[USER_GUIDE.md](USER_GUIDE.md)**。

不想折腾环境的话，仓库的 **Releases** 页面提供 `Clicker-Setup-1.0.0.exe`（安装包）和免安装
的 `Clicker.exe`（需连同 `_internal` 一起下载）；仓库里只放源码和文档，编译产物由
`.gitignore` 排除。

用 Python 3 编写，只依赖标准库（`tkinter` + `ctypes` 直接调用 Win32 的 `SendInput`、
底层钩子和 `RegisterHotKey`），不需要 pip 安装任何东西，也不用编译。相比 C++/Java，
这套组合能同时拿到系统级的输入注入精度和开箱即用的界面。

## 启动

免安装，直接双击 **`Clicker.exe`**（1.9 MB，旁边的 `_internal` 是它的运行时，两者必须同目录）。
程序不依赖系统临时目录，启动即用；`%TEMP%` 不可用或被安全软件拦下等情况都不会再影响启动。

想装进开始菜单、能在控制面板里卸载，就运行安装包 `build\installer\Clicker-Setup-1.0.0.exe`，
做法见下面的[安装包](#安装包)。

也可以在源码模式下运行：

```
python main.py            # 或双击 start.bat
```

要求：Windows 10/11。两种启动方式都会自动开启 DPI 感知，高分屏下界面不模糊、
坐标与系统一致。

## 打包成 exe

`Clicker.exe` 已经在本文件夹里；改了代码后重新生成：

```
build\venv\Scripts\python.exe -m PyInstaller --noconfirm ^
  --distpath "build\dist" --workpath "build\work" "build\clicker.spec"
build\venv\Scripts\python.exe build\finalize.py      # 把产物铺到本文件夹
```

或者双击 `build\rebuild.bat`（没有 venv 时会自动创建并装 PyInstaller）。图标、版本信息、
中文名等配置都在 `build/clicker.spec` 里，改配置改这个文件就行。

这里特意用 **onedir**（exe + `_internal`）而不是 onefile：onefile 每次启动都要把运行时
解压到 `%TEMP%`，只要用户会话的临时目录不可用，双击就会弹
`Could not create temporary directory!`；onedir 没有这一步，启动也更快。
`build/` 目录只是打包工具链（venv、图标生成脚本、spec、版本信息），删掉不影响程序
本身，重新打包时再生成。

## 安装包

要在别的机器上正式安装（开始菜单快捷方式、控制面板可卸载），先按上面打包出 `Clicker.exe`
和 `_internal`，再双击：

```
build\make_installer.bat        # 等价于 ISCC.exe build\installer.iss
```

产物是 `build\installer\Clicker-Setup-1.0.0.exe`（约 9.4 MB），它把 exe、`_internal`、
`README.md`、`USER_GUIDE.md` 一起装上，行为如下：

- 默认装到 `%LOCALAPPDATA%\Programs\Clicker`，全程**不需要管理员权限**；安装程序开头问
  “为所有用户安装/仅为当前用户安装”时选了前者才会弹 UAC，那时装到
  `C:\Program Files\Clicker`，脚本会自动给安装目录补上普通用户的修改权限，否则 `data\`
  写不进去，录制和宏就存不下来。
- 卸载只删程序自己的文件，`data\`（设置、录制、宏）会保留，卸完还会弹窗告诉你它留在哪儿，
  重装即恢复。
- `installer.iss` 里 `AppId` 固定，升级安装覆盖同一份而不会留下两个卸载项；升级前
  `{app}\_internal` 整体清空，避免残留上一版用不到的 dll。
- 本机 Inno Setup 7.1.1 对非商业使用免费，编译开头会打印 `Non-commercial use only`，
  那不是报错。

`python tests\installer_check.py` 会把整条链路自检一遍：编译 → 静默安装 → 对新装出来的
exe 跑 `exe_check` → 静默卸载 → 确认 `data\` 还在。

## 连点

| 设置 | 说明 |
| --- | --- |
| 点击类型 | 鼠标左键 / 右键 / 中键 / 滚轮向上 / 滚轮向下 / 键盘按键 |
| 点击间隔 | 预设 `0.1 秒`、`0.01 秒`，选“自定义”后填任意值（0.001–3600 秒） |
| 点击次数 | `0` 表示不限，直到再次按热键或点“停止” |
| 固定位置 | 勾选后每次点击前先把光标移到指定坐标；“取光标位置”是先按按钮、再到目标位置点一下鼠标，那一点即坐标（点自己窗口无效） |

## 录制

按启停热键开始录制，再按一次结束。录制内容包括鼠标按下/松开、滚轮、键盘按键，
以及按 20 ms 采样一次的鼠标轨迹；每个事件带自己的时间间隔，播放时按原节奏重现。

录完填写名称点“保存”即写入本地。列表里选中一条可以“播放选中”，也可以给它绑定
**调用快捷键**——之后在任何程序里按这个组合键就直接执行这段录制。

## 宏

宏是一串步骤，可循环执行（次数填 `0` 为不限）。支持的步骤：

`调用已录制操作`、`鼠标点击`、`移动鼠标`、`滚轮滚动`、`按下按键`、`组合键`、
`输入文本`、`等待`。

其中“调用已录制操作”直接从录制列表里选，这就是宏与录制的衔接点。每个宏同样可以
绑定独立快捷键。

## 快捷键

| 键 | 作用 | 在哪改 |
| --- | --- | --- |
| `F8` | 启停**当前所在页**的功能：连点页启停连点，录制页启停录制，宏页运行/停止选中的宏 | 选项页 |
| `F9` | 急停，停掉连点、录制和宏的全部后台任务，也会取消等待中的延时播放 | 选项页 |
| `F7` | 回放最近一次保存的录制 | 选项页 |
| 自定义 | 每个录制、每个宏都能绑定自己的全局快捷键 | 录制页 / 宏页 |

`F8`/`F9`/`F7` 都可以在界面上改：把光标放进快捷键输入框，直接按下想要的组合键即可
捕获（支持 Ctrl/Alt/Shift/Win 组合）。这些是系统级 `RegisterHotKey` 全局热键，程序
在后台也生效；若被其他程序占用，状态栏会提示注册失败。

录制期间按下的启停热键本身不会被录进结果，程序自己注入的事件也不会被重复录制。

## 选项

第四个页签放跨功能的设置，这一页自己不参与 `F8` 启停：

- **启停热键**、**急停热键**、**回放上次录制**三个全局快捷键（启停热键从连点页搬过来，
  急停从底部状态栏搬过来）。
- **播放前先最小化本窗口**：播放录制或运行宏时收起界面，结束后自动还原。
- **延时 N 秒后开始**：倒计时期间状态栏显示剩余秒数，按急停可取消；这段时间够把
  焦点切到目标窗口。

配套的执行反馈：录制和宏共用一个执行通道，播放期间录制页与宏页的按钮自动置灰，
只留“停止播放”/“停止运行”可点，结束时状态栏明确写“播放完成：录制「xxx」”或
“已停止播放：录制「xxx」”。

## 本地数据

全部保存在**程序所在文件夹**的 `data/` 下，UTF-8 JSON，可以直接手工编辑或用版本管理跟踪。
用 exe 运行时以 exe 同级目录为准，用 `python main.py` 运行时以项目根目录为准：

```
data/config.json                 界面设置、快捷键、连点参数、播放选项
data/recordings/<名称>.json      录制内容（含各自的快捷键）
data/macros/<名称>.json          宏定义（步骤、循环次数、快捷键）
```

文件名即录制/宏的名称，重命名会写新文件并删除旧文件。读取时会校验字段，损坏的文件
在列表里标为“（文件损坏）”，不会被程序改写。

## 代码结构

```
main.py                入口
start.bat              从源码启动（无控制台窗口）
README.md              项目说明
USER_GUIDE.md          详细使用说明
Clicker.exe            打包好的程序（双击即用）
_internal/             exe 的运行时，必须与 exe 同目录
clicker/win32.py       SendInput 输入注入、底层键盘/鼠标钩子、全局热键、键码表
clicker/store.py       配置与录制/宏文件的原子读写和字段校验（冻结态下按 exe 定位数据目录）
clicker/engine.py      连点、录制会话、宏执行器（全部在可中断的后台线程里）
clicker/app.py         Tkinter 界面：连点/录制/宏三个功能页 + 选项页 + 快捷键调度 + 线程安全回调桥
build/                 打包工具链：venv、图标脚本、clicker.spec、finalize.py、rebuild.bat、
                       installer.iss、make_installer.bat、installer\ 里放着安装包
```

界面线程从不执行输入或等待，所有耗时操作都在后台线程；后台回调通过队列回到主线程，
因此连点运行时界面依然可以正常点按和停止。

## 自检

```
python -m unittest discover -s tests   # 17 项：存储校验、连点/宏逻辑、键码解析
python tests/live_check.py             # 8 项：真实 SendInput + 钩子回环 + 热键触发
python tests/gui_flow_check.py         # 29 项：驱动界面方法跑通连点/录制/宏、选项页、取坐标与文件保存
python tests/exe_check.py              # 7 项：起窗口、不碰 %TEMP%、数据落在 exe 同级、DPI、图标、干净退出
python tests/installer_check.py        # 13 项：安装包编译、静默安装、卸载后 data 保留
```

中间两个脚本需要桌面会话，会真的移动光标、按键（只用 F13 和空白窗口区域，不影响其他
程序），运行时请不要同时开着界面实例抢热键。`exe_check.py` 会把 exe 和 `_internal` 一起
复制到临时目录再启动，以此验证数据目录的落点，不会改动 `data/` 里已有的内容。
`installer_check.py` 需要本机装过 Inno Setup，它只往 `build/selftest/` 里装和卸，不写
注册表卸载项、不建快捷方式，跑完自动清理。

## 已知限制

- 目标是**以管理员身份运行**的窗口时，本程序也需以管理员身份运行，否则系统会拦截注入。
- 部分游戏使用反作弊输入通道，会忽略 `SendInput` 产生的事件，这是系统层面的限制。
- 快捷键不能重复绑定，冲突时状态栏会指出被哪两个功能同时占用。
- 同时开两份程序会有一份抢不到热键（状态栏提示注册失败），只保留一份即可。
- 拷到别的电脑要连 `_internal` 一起拷，只拷 `Clicker.exe` 会起不来；嫌麻烦就用安装包。
- 安装包只面向 x64 的 Windows 10/11；制作它需要本机装有 Inno Setup 7，编译开头打印的
  `Non-commercial use only` 是授权声明，不是报错。
- PyInstaller 产物偶尔被个别杀毒软件误报。遇到时改用源码方式 `python main.py` 运行，
  或给 `Clicker.exe` 加白名单。
